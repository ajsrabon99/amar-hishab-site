What the app does

Amar Hishab is built for personal record keeping. These are its main functions.

Income & expense tracking

Record income and expenses, add a category, date and note, and review your transaction history.

Accounts

Keep separate balances for bank, bKash, Nagad, cash and other accounts the app supports.

Balance overview

See your overall balance and an income/expense overview. Balance can be hidden or shown.

Categories

Income and expense categories are included, and you can manage custom categories to fit your needs.

Reports

Review summaries of income and spending to understand where your money goes.

Savings goals

Create savings goals and follow how much you have saved so far.

Import / export

The app offers import and export. Check inside the app for the exact formats it supports.

Themes

Light, dark and system themes.

Personal use

The app is designed for managing personal finances. See the Privacy Policy for details.

Saving up

Backup & Restore

Your financial records are important. Before updating or reinstalling the app, always create a backup.

Create a backup

Settings → Data Backup → Create Backup

Save the ZIP file somewhere safe.

Restore your data

Settings → Restore Data → select backup ZIP → Restore

Never delete your old backup until you have successfully restored and verified your data.

How to Download & Install

  1. Click “Download APK”.
  2. The GitHub Release page opens.
  3. Pick the APK file under Assets.
  4. When it finishes, open the file.
  5. If Android asks, allow the needed installation permission.
  6. Install.
  7. Open the app and restore your data if needed.
Android may show a warning for APKs installed from outside Google Play. Only download from the official GitHub Release, and don’t turn off security features you don’t need to.

How to Update Amar Hishab

  1. Open Amar Hishab.
  2. Go to Settings.
  3. Create a Data Backup.
  4. Save the ZIP safely.
  5. Download the latest APK from the official GitHub Release.
  6. Install or update the app.
  7. Open the new version.
  8. If needed, use Restore Data with your backup.
Always keep a backup before updating or reinstalling.

FAQ

What is Amar Hishab?

An Android app for keeping personal income, expense, balance and savings records.

Is it free?

Check the GitHub Release page for the latest information.

Where do I get the APK and how do I install it?

From the official GitHub Release page. The steps are in the install section above.

Will my data be deleted when I update?

To be safe, back up first. You can restore afterwards if needed.

How do I back up and restore?

Settings → Data Backup → Create Backup. To restore: Settings → Restore Data.

The APK won’t install. What now?

Check the download finished fully, allow installation permission, and if it still fails report it on GitHub Issues.
