# Amar Hishab website
Static site (HTML/CSS/JS). Deploy: on Render create a Static Site, publish directory = this folder, no build command.
1. Replace every YOUR-DOMAIN.example in index.html, privacy.html, disclaimer.html, robots.txt, sitemap.xml.
2. Screenshots: add images to assets/screenshots/, replace the .shot placeholder divs in index.html (comment shows how).
3. AdSense (after approval): paste Google's script in <head> of each page, and the ad unit code inside the three .ad-slot divs (search "GOOGLE ADSENSE SLOT"). Keep them away from the Download buttons. Replace ads.txt content with the line Google gives you (your real pub-ID). Add a consent banner if your audience requires it.
4. Fill in every [CUSTOMIZE] item in privacy.html and disclaimer.html.
5. Replace assets/logo/logo.svg with your real logo (keep the file name or update references).
